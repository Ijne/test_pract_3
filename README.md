# Планировщик бюджета — вариант 61

Учебный проект для практической работы «Подходы для разработки программного
обеспечения». Приложение позволяет установить бюджет, зарегистрировать расходы,
рассчитать остаток и сформировать отчёт по категориям.

Проект демонстрирует четыре подхода:

- TDD — модульные тесты предметной логики;
- ATDD — приёмочные пользовательские сценарии;
- BDD — автоматизированные сценарии Given–When–Then;
- SDD — табличная спецификация с конкретными примерами.

## Требования

- Python 3.10 или новее;
- дополнительные библиотеки не требуются.

## Запуск программы

```powershell
python demo.py
```

## Запуск тестов

Из корневого каталога проекта:

```powershell
python -m unittest discover -s tests -v
```

Ожидаемый результат: 10 успешно выполненных тестовых методов. Внутри них
дополнительно проверяются два BDD-сценария и четыре SDD-примера.

## Структура

- `budget_planner.py` — предметная модель;
- `demo.py` — демонстрационный запуск;
- `tests/` — TDD, ATDD, BDD и SDD-тесты;
- `features/` — сценарии Gherkin;
- `specifications/` — исполняемые табличные примеры.
